## Use This API in a Custom Family

Public modules on this page may be used as complete transitions or as source,
self, local, global, and readout components inside another SILVA point. The
[extensibility API](extensibility.md) validates the universal tensor contract;
the [extension tutorial](../learn/extending-silva.md) derives the construction,
shows module replacement, and defines compact and full reproduction tests.

When replacing a built-in component, retain its documented domain invariants
in addition to shape, device, dtype, finiteness, and gradient compatibility.
