## Reproduction Standard

An executable smoke run validates wiring. A compact reproduction additionally
requires deterministic data, an independently stated metric, a baseline,
declared thresholds, and a complete configuration. A published benchmark
reproduction also requires the original data version, split, preprocessing,
schedule, several seeds, and an explicit record of every deviation.

Use [Extending SILVA](../learn/extending-silva.md#8-four-validation-levels)
for the four validation levels and
[Reconstructing Paper Experiments](../learn/reconstructing-paper-experiments.md)
for the complete experiment record.
